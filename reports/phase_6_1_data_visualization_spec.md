# CreditAI Phase 6.1 — Data Visualization Specification

## Evidence rules

- All LendingClub views use the sanitized aggregates in `frontend/public/data/phase_6_1_lendingclub_summary.json`, generated by a streaming script from local source DS001. Browser payloads contain no raw loan rows, direct identifiers, or individual prediction scores.
- Portfolio rates are `closed defaults / closed outcomes`; show the count of all records and closed denominator alongside the rate. They are terminal closed-loan rates with variable outcome horizon, not fixed-horizon PD.
- Evaluation metrics are read from the saved Phase 2.3 benchmark CSVs, not recomputed from invented score distributions. The untouched test is 2016–2018; thresholds 0.16/0.17 were selected on validation by F1 maximization. Prevalence baseline PR-AUC equals test prevalence (0.2242); constant-score ROC-AUC is undefined.
- Model comparison may show ROC-AUC, PR-AUC, Brier, log loss, selected threshold, precision, recall and F1 because these values are saved. ROC/PR curve, calibration curve, score histogram, confusion matrix heatmap, and local explanation panes remain unavailable where saved coordinates/rows are absent; do not infer curves from scalar metrics.
- Source labels: historical DS001; synthetic DS008–013; unavailable for mixed inventory/remote candidates; live API explicitly unvalidated. Keep labels adjacent to chart/page context.
- Missingness and correlations are descriptive dataset diagnostics, not evidence of causation. Small segments retain sample and closed denominators. No PII appears.

All custom SVG visualizations use native title text or adjacent value labels, visible axes/units where applicable, responsive viewBox sizing, and accessible labels. Color is redundant with labels/status text. Avoid decorative graphics without data.
